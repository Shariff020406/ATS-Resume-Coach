# ATS-Resume-Coach

🤖 What is this Bot?
The ATS Resume Coach (@Shaik_ats_bot) is an AI-powered Resume Evaluator & Career Coaching Bot on Telegram. It simulates how corporate Applicant Tracking Systems (ATS) screen resumes, analyzes candidate fit against target Job Descriptions, and provides actionable upskilling roadmaps with direct course enrollment links.

🚀 How It Works (The 2-Step Workflow)
Step	User Action	What the Bot Delivers
Step 1	Upload Resume
(PDF or DOCX document)	• Extracts technical skills & ATS formatting parseability score.
• Immediately generates & sends a visual dark-theme Skills Competency Chart (PNG photo).
Step 2	Paste Desired Job Description
(Any role or job posting)	• Calculates an ATS Compatibility Match Score (0–100).
• Identifies Matched Skills vs Missing Gaps.
• Recommends curated online courses (Coursera, edX, Udemy) tailored to that specific job.
• Sends a 4-Axis Role Compatibility Matrix (Radar Chart PNG photo).
🌟 Core Highlights & Capabilities
⚖️ Zero Experience Bias Scoring:
Evaluates candidates strictly on skills and impact rather than tenure:
Technical Skill Alignment: 70%
ATS Machine Formatting & Parseability: 15%
Action Verbs & Impact Metrics: 15%
🎓 Role-Adaptive Course Recommendation Engine:
Dynamically customizes recommended courses for 15+ career tracks (Frontend, Java/Spring Boot, Data Analytics, Mobile/Flutter, Cybersecurity, UI/UX, Full Stack, DevOps, etc.).
Never shows repetitive or generic courses — every Job Description gets courses tailored to its exact stack.
📊 Server-Side Dark-Theme Visual Charts:
Uses Matplotlib to render high-resolution PNG charts (Skills Profile & Radar Chart) directly inside the Telegram chat.
👥 Multi-Resume Candidate Comparison:
For a single Job Description, you can upload multiple resumes to rank candidates on a leaderboard with side-by-side match scores.
